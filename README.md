# NPC角色卡动态加载器 v0.5

这是“精准当前轮”版。

## 核心修复
v0.4 会同时扫描“当前用户消息 + 上一条AI回复”，所以如果AI回复继续提到上一位NPC，就会出现：
娜娜 → 娜娜+露西亚 → 娜娜+露西亚+芙宁娜 的累积现象。

v0.5 **只扫描本轮最新用户消息**：
- `娜娜怎么看？` → 只加载娜娜
- 下一轮 `露西亚呢？` → 只加载露西亚
- 下一轮 `芙宁娜怎么看？` → 只加载芙宁娜
- `娜娜和露西亚都说说` → 同一轮加载娜娜 + 露西亚

`@名字`仍然可用，但不是必须。

## 设计取舍
暂时取消“从上一条AI回复自动维持在场NPC”。这是有意为之：
宁可少加载，也不要让角色卡无限累积、浪费上下文并互相污染人格。

后续如果需要真正的“在场角色池”，应通过明确的进场/离场状态维护，而不是从AI回复里猜。
